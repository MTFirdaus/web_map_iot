# IoT GPS Tracking Web Application

Aplikasi web pemantauan lokasi real-time berbasis IoT menggunakan ESP8266, PHP, MySQL, dan Leaflet.js.

## Fitur
- Pengiriman koordinat GPS otomatis dari ESP8266 via HTTP POST API.
- Penyimpanan data lokasi ke database MySQL.
- Tampilan peta interaktif menggunakan OpenStreetMap & Leaflet.js.
- Real-time auto update marker lokasi pada peta.

## Tech Stack
- **Hardware/Firmware:** ESP8266, Arduino IDE, C++
- **Backend:** PHP, MySQL
- **Frontend:** HTML, CSS, JavaScript (Leaflet.js)
